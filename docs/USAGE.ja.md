# 操作方法

Windows / UE 5.8向けの初期版です。SteamVRをOpenXRランタイムに指定し、
HMD・バー中央のTracker・心拍計を起動します。ローイングマシンは漕いで
起こしてください。スマートフォンのアプリが接続中なら切断します。

PowerShellでこのリポジトリを開き、`./tools/run.ps1` を実行します。
機器を使わないデモは `./tools/run.ps1 -Demo` です。

- 普段の姿勢でマシンの正面を向き、バーを伸ばして **テンキーEnter**：開始。
- **テンキーEnter**：一時停止／再開。再開時も正面と体の中心を合わせます。
- **テンキー0**：記録を保存して停止し、湖上の出発位置へ戻ります。
  Num Lockがオフの場合のInsertと、Escでも停止できます。
- 体を左／右に移動すると左／右へ操舵します。
- HMDまたはTrackerの追跡を失うと停止します。復旧後にEnterで再開します。

通常のキーボードのEnterでも操作できます。長押しは1回の操作として扱います。
キー操作の対象はゲームウィンドウです。反応がない場合はPC側でゲーム画面を
クリックしてから押してください。`Enter received / check HMD + bar` はキーを
受け取ったものの追跡条件を満たしていない状態です。正面を向き、HMDとTrackerの
追跡を確認してから再度テンキーEnterを押します。

距離・速度は仮想の艇が実際に進んだ値です。時間は一時停止を除く開始後の
経過時間です。心拍数が未受信、接触不良、または5秒以上更新されない場合は
`--` と表示します。本体の出力が受信できない場合は、Trackerから推定する
モードであることを表示します。

記録先は `unreal/ArriettyRow/Saved/Sessions/` のCSVです。艇の距離・時間・速度・
心拍数に加えて、本体が報告する距離・時間・速度・出力も別の列に保存します。
本体の列は本体側の累積値です。テンキー0は本体のカウンターをリセットしません。
デモの記録は `source=demo` で区別します。個人の機器IDと運動記録は公開しません。

`./tools/probe.ps1 -Seconds 60` でC++の受信を確認できます。別の受信テストや
ローイングアプリと同時に実行せず、表示を確認しながら20～30秒漕いでください。
初回は `./tools/build_native.ps1 -Devices` で受信テストをビルドします。

開発時の準備は `./tools/prepare.ps1`。別に作ったLakeBled UEプロジェクトから
素材をコピーし、Arrietty-row専用のマップを作ります。現在の実機検証範囲は
[VALIDATION.md](VALIDATION.md) を参照してください。
