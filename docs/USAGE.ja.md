# 操作方法

Windows / UE 5.8向けの正式版1.1.0に、採用済みの負荷連動の推進力・W表示・
高速時の旋回改善を加えた版です。ケルビン波と速度に応じた舳先の白波を含みます。
通常の `Arrietty-row` フォルダーから起動します。SteamVRをOpenXRランタイムに指定し、
HMD・バー中央のTracker・心拍計を起動します。ローイングマシンは漕いで
起こしてください。スマートフォンのアプリが接続中なら切断します。

PowerShellでこのリポジトリを開き、`./tools/run.ps1` を実行します。
機器を使わないデモは `./tools/run.ps1 -Demo` です。

- **テンキーEnter**：開始前の校正へ進みます。下の3段階で自動的に開始します。
- 運動中の **テンキーEnter**：一時停止。再開時も校正します。
- **テンキー0**：記録を保存して停止し、湖上の出発位置へ戻ります。
  Num Lockがオフの場合のInsertと、Escでも停止できます。
- 体を左／右に移動すると左／右へ操舵します。
- HMDまたはTrackerの追跡を失うと停止します。復旧後にEnterで再開します。

開始・再開の手順：

1. `1/3 GET READY`：Enterから2秒間、キーから手を戻して普段の姿勢になります。
2. `2/3 HOLD STILL`：マシンの正面を向き、体を中心にして1秒間静止します。
   この間のHMD位置を平均して中心を決めます。姿勢が動くと1秒を数え直します。
3. `3/3 ROW THE BAR 0 / 2`：左右に体を傾けず、バーをまっすぐ前後に2往復します。
   40cm以上の十分なストロークで行います。軸を取得すると自動的に運動が始まります。

校正中は艇が動かず、仮想の距離・運動時間・ストローク数にも加算しません。
校正中にEnterを押し直しても校正は中断しません。やり直す場合はテンキー0で停止し、
Enterから再開します。校正前・校正中の案内はHMDから見やすい位置に表示し、
完了後は艇上の計器位置へ戻ります。表示は `1/3` → `2/3` → `3/3` と進みます。
40秒以内に校正できなかった場合はタイムアウトして待機します。追跡が失われた場合も
自動的に進み出さず、機器と姿勢を確認してEnterからやり直します。

左右の方向はバーの往復から求め、顔の角度で左右軸を決めません。中央から
**左右±8cmは直進範囲**です。範囲を超えると穏やかに曲がり始め、20cmで最大になります。
高速域では船速に合わせて旋回速度が増え、最大舵で半径約10mを目標に曲がります。
18cmの横移動なら半径約14.4mが目安です。傾け始めや加速中は平滑化の影響があります。
計器の緑の帯が直進範囲、動く目印が現在の左右位置です。`CENTER` は直進、
`LEFT` / `RIGHT` はその方向への操舵を示します。数値は中心からの左右位置（cm）です。
表示と操舵には同じ平滑化した位置を使い、緑の帯へ戻ると曲がり残りを止めます。
漕いでいる間は中心や軸を自動で動かしません。詳細は [STEERING.md](STEERING.md)。

通常のキーボードのEnterでも操作できます。長押しは1回の操作として扱います。
キー操作の対象はゲームウィンドウです。反応がない場合はPC側でゲーム画面を
クリックしてから押してください。`Enter received / check HMD + bar` はキーを
受け取ったものの追跡条件を満たしていない状態です。正面を向き、HMDとTrackerの
追跡を確認してから再度テンキーEnterを押します。

距離・速度は仮想の艇が実際に進んだ値です。時間は一時停止を除く開始後の
経過時間です。心拍数が未受信、接触不良、または5秒以上更新されない場合は
`--` と表示します。本体の出力が受信できない場合は、Trackerから推定する
モードであることを表示します。

計器の小さい行に `BT 80 W | LOAD 6 | GAME 480 W` のように、本体のW・
ダイヤルの負荷・ゲーム用の補正Wを表示します。**補正W = 基準W × 負荷レベル**
で推進力を計算します。基準Wは本体の受信Wを優先し、未受信または3秒以上
古いときはバー速度からの推定値（`Tracker est`）です。負荷は受信するたびに
反映するので、運動中のダイヤル変更にも追従します。負荷が未受信、1～16の
範囲外、または3秒以上古い場合は `LOAD -- (x1)` と表示して倍率1を使います。
補正Wはゲーム用の調整値で、身体の実測出力ではありません。基準Wの上限は
BTで1000 W、Tracker推定で240 Wです。船には従来の水抵抗・加速上限・速度上限
が働くので、負荷を6倍にしても速度がそのまま6倍になるわけではありません。
ハンドルを止めると推進は止まり、艇は惰性で進みます。負荷は本体のダイヤルで
変更し、アプリから本体を操作しません。

記録先は `unreal/ArriettyRow/Saved/Sessions/` のCSVです。艇の距離・時間・速度・
心拍数に加えて、本体が報告する距離・時間・速度・出力も別の列に保存します。
左右位置、操舵量、旋回速度も保存し、偏りを後から確認できます。
`power_w` は本体の元のWです。`resistance_level` に受信負荷、`power_multiplier`
に実際の倍率、`game_power_w` に補正Wを記録します。不明な負荷・Wは空欄です。
補正Wは推進力に使う出力の値であり、校正中・一時停止中に受信しても艇や運動時間
は進みません。待機・一時停止中も、新しい本体Wと負荷は画面に表示します。
本体の列は本体側の累積値です。テンキー0は本体のカウンターをリセットしません。
デモの記録は `source=demo` で区別します。個人の機器IDと運動記録は公開しません。

`./tools/probe.ps1 -Seconds 60` でC++の受信を確認できます。別の受信テストや
ローイングアプリと同時に実行せず、表示を確認しながら20～30秒漕いでください。
初回は `./tools/build_native.ps1 -Devices` で受信テストをビルドします。

開発時の準備は `./tools/prepare.ps1`。別に作ったLakeBled UEプロジェクトから
素材をコピーし、Arrietty-row専用のマップを作ります。現在の実機検証範囲は
[VALIDATION.md](VALIDATION.md) を参照してください。
