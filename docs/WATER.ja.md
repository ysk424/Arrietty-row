# ケルビン波の実装と確認手順

ケルビン波は別の worktree の `feat/kelvin-wake` ブランチに実装しています。
**main は今までのトレーニング版のままです。現在は未統合です。**

## 実機テストと統合の順序

1. 開発側で計算・ビルド・UE の描画と操作の回帰テストを行います。これは完了しています。
2. **worktree 版を実機で試します。これはまだ行っていません。**
3. 実機テストの結果を確認し、必要なら worktree 内で修正します。
4. ユーザーから統合の指示を受けてから、main に統合してトレーニング版を更新します。

検証 PNG がよさそうという評価を、main への統合承認として扱いません。
実機テストが終わっただけでも自動的には統合しません。

実機で確認する中心は、水面の見え方が好みに合うか、今までどおり気持ちよく
漕げるかです。特に、波の見え方、HMD での滑らかさ、開始・一時停止・再開、
左右の操舵に違和感がないかを確認します。計算とコードの検証は開発側で担当します。

## 今回の変更

- 船首・船尾から生じる、横向きの波と斜めに広がる波を計算します。
- 波長によって伝わる速さが変わる性質を使い、航跡の形を生じさせています。
- 曲がった後も、以前の航跡は水面上に残って広がります。
- 停止すると新しい航跡の発生が止まり、残った波は広がりながら弱くなります。
- **舳先に、艇速に応じた白波を追加しました。** 約 0.4 m/s 以下では発生せず、
  速くなるにつれて量と広がりが増え、約 2.6～3 m/s で強い表現になります。
  オールを引いている瞬間だけでなく、艇が惰性で進んでいる間も速度に応じて発生します。
  舳先の外側から左右に分かれ、小さな盛り上がりを伴います。停止後は泡が薄れていきます。
- 水面基準 Z=0、ブレッド湖の遠景、通常の乗艇視点と操作を維持しています。

## PNG と実際の見え方

赤・青の検証画像は、計算した水面の高さを色で表した図です。
波の形や間隔を確認するためのもので、ゲーム画面の配色ではありません。
UE のゲーム画面では、その波を水面の凹凸と光の反射として描画します。
太陽の反射や見る角度によって、航跡の目立ち方が変わります。

現時点の検証結果：

- 既存 76 チェックと水面 46 チェックが成功。白波の速度依存・発生位置・左右対称性・
  向きへの追従・停止後の減衰も確認しています。
- UE 5.8 の Editor／Game ビルドと、Enter・停止・再開などの回帰テストが成功。
  白波追加後の操作テストは、初回が完了前に終了し、同じ実装での再実行で成功しました。
  初回終了の原因は特定できていません。詳細を検証記録に残しています。
- 直進・旋回・通常の乗艇視点を、機器を使わない UE のデモ描画で確認。
- 波の計算は、この PC の単体計測で平均約 1.54 ms／更新。
  HMD を含むゲーム全体の処理時間ではありません。
- **この変更を使った実機トレーニング、HMD での快適さ、長時間の負荷は未確認。**

## worktree 版を起動する場合

実機テストを行う時に使う手順です。現行版を終了してから、PowerShell で
worktree のフォルダーを開きます。現在の配置では、元の `Arrietty-row`
フォルダーから次のように移動できます。

```powershell
Set-Location ../Arrietty-row-worktrees/kelvin-wake
```

SteamVR と普段の機器を準備し、worktree 側で実行します。

```powershell
./tools/run.ps1
```

操作は従来どおりです。Enter → 2 秒待機 → 1 秒静止 → バーを 2 往復で開始。
Enter で一時停止・再開、テンキー 0 で停止・出発位置へ戻ります。
左右 ±8 cm の直進範囲も同じです。詳しくは [操作方法](USAGE.ja.md) を参照してください。

機器を使わずに通常のデモを見る場合：

```powershell
./tools/run.ps1 -Demo
```

この起動や実機テストでは main は更新されません。設定・生成素材・ビルド結果・
運動記録は worktree 側に分離されています。

## モデルの限界

深い水域の小さな波を近似した、艇周辺 64 m の計算です。
浅瀬による変化、岸での反射、砕ける波などは計算していません。
舳先の白波は、速度から調整する視覚表現です。泡の粒子や砕波の流体計算ではありません。
物理モデルの詳細は [英語の技術説明](WATER.md)、測定記録は
[検証記録](VALIDATION.md) にあります。
